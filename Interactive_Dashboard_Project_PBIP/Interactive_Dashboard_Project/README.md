# Project 02 — Interactive Power BI Dashboard

Power BI Project (PBIP) for the RealMart retail sales analysis.

## Dashboard contents
- 4 KPI cards
- Sales by Product Line
- Sales by Branch
- Monthly Sales Trend
- Payment Method Distribution
- Sales by City
- Branch, City, and Product Line slicers

## Open
Open `Interactive_Dashboard_Project.pbip` in Power BI Desktop.

This project contains the semantic model and embedded data. After opening successfully in Power BI Desktop, use **File → Save As** if you need the conventional `.pbix` submission format.
