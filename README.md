# Data Analytics Internship

This repository contains the projects completed as part of the Data Analytics Internship.

## Projects

### Project 01 — Retail Sales & Customer Behavior Analysis

Python-based retail sales analysis using Pandas, NumPy, Matplotlib, and Seaborn.

**Includes:**
- Data cleaning and type conversion
- Exploratory Data Analysis (EDA)
- GroupBy analysis
- Correlation analysis
- Data visualizations
- Business insights and recommendations
- Cleaned dataset for Project 02

Location: `Project_01_Retail_Sales_Analysis/`

### Project 02 — Interactive Power BI Dashboard

Interactive Power BI dashboard built using the cleaned dataset from Project 01.

**Includes:**
- KPI measures
- Sales by branch, city, and product line
- Monthly sales trend
- Payment method analysis
- Interactive slicers and filtering

Location: `Project_02_PowerBI_Dashboard/`

### Project 03 — AI-Assisted Business Analytics Capstone

Capstone project covering sales analytics, generative AI prompt creation, prompt engineering, responsible AI, data privacy, and business recommendations.

**Includes:**
- 40-row sales dataset
- Sales analysis
- Two charts
- Five AI prompts
- Two basic-vs-improved prompt comparisons
- Responsible AI analysis
- Data privacy analysis
- Final report
- Presentation

Location: `Project_03_AI_Business_Analytics/`
